## 冻结要点

- wireRevision 3，服务端支持 [1,2,3]，包版本 0.9.0；新增 91 个类型、48 个修订 3 帧、99 份合成 Fixture；旧 Fixture 与修订 1/2 的线形不变。
- 未导入的终端会话只同步索引，标题脱敏后最多 120 码点。正文走 10 秒 / 1MiB 的临时查询，不进可靠事件流，也不在云端落库。导入后完整同步，含续接前的历史（与 §8.3a 一致）。
- 活跃状态为 unknown 时只读；关闭确认要留审计；正向的活跃证据不能被勾选覆盖；每次续接前再检查；同一原生 ID 同时最多一个写进程。
- 授权根目录只能在电脑上配置，默认为空，最多 32 个；云端只能看到 rootId、名称、版本，看不到绝对路径。逐层浏览每次最多 100 条，只接受电脑签发的短期选择引用，不接受路径。
- 六条新 HTTP 操作只接受 Cookie；暂停门禁禁止浏览、导入、登记，历史只读仍允许。
- 新增 9 个错误码（查询超时 / 过大、原生会话活跃 / 不支持 / 已变更 / 写冲突、根未授权、路径越界、目录已变更），只属于 HTTP / 修订 3。
